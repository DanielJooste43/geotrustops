One glow per changed record; where records overlap, the glow brightens.

Kernel-smoothed density of the changed records shown. It shows where record changes concentrate, not where data is wrong.

Drag the divider (or focus it and use the arrow keys). Left of it: each changed record where it was in the earlier release; right of it: where it is in the later release. Removed records appear only on the left, added records only on the right. Stacked-place flags describe the later release, so they show on the right.

Records added, removed or moved in the chosen release; the two releases before it fade out. Records that moved are drawn with an amber core. Select a glow to see that record's positions by release.

About the trails and dates

Each line joins a record's last-seen position to its position in the chosen release (or one of the two before it); a record's full trail is listed in its details. Overture's changelogs give positions per release, not dates within it, so the lines are steps between releases, not observed paths.

What is a stacked place?

Places within 2 m of each other in the current release, with a likely cause from simple checks; each group needs manual inspection.

How to read this map

    What this map is not

    Changes are changes to map records between two releases. An added record is not a business opening, a removed record is not a closure, and a moved record does not mean the earlier position was wrong.
