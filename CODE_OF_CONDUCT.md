# Code of Conduct

This project welcomes anyone who wants to use it, question it or improve it. This page applies to issues, pull
requests, reviews and any other project space.

## Expected

- Be respectful and assume good intent; disagree with ideas, not people.
- Keep feedback specific and about the work: the code, the data, the method.
- Respect privacy: do not post personal details about anyone, including details found in map data.

## Not acceptable

- Harassment, insults, discriminatory remarks or personal attacks.
- Sharing someone's private information without their permission.
- Sustained disruption of discussions, or any conduct that would be unwelcome in a professional setting.

## Reporting

Report a problem privately to the maintainer through GitHub: on this repository, open **Security → Report a
vulnerability** and start the title with "Conduct:". Reports are kept confidential, acknowledged within seven days,
and handled fairly, with the person reported given a chance to respond.

## What happens

Depending on what happened, the maintainer may ask for a change in behaviour, edit or remove comments, or block
someone from the project. The aim is a project where everyone can take part.
